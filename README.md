# 墨案

> 专为电子墨水屏打造的 Android 本地阅读器，支持 EPUB 与漫画。  
> 致虚守静，专于一境：将整理好的本地藏书整饬陈列，开卷即读，不着冗物。

*(曾用名：书巢)*

- **迅疾轻盈**：冷启动至书架仅约 0.8 秒；文字秒开出字（约 0.6 秒），漫画瞬开（约 0.25 秒）；单页翻动 CPU 耗时仅 60–85 毫秒。
- **因墨而生**：全应用摒弃任何过渡动画、渐变色与装饰冗线，操作动辄一帧瞬切，不拖影、不闪烁；静读之时，CPU 占用几近归零。
- **纯粹离线，恪守私密**：绝不联网，不设后台常驻进程，无需敏感的全局存储权限；借由系统 Storage Access Framework 仅读所选目录，绝不擅改书目文件。
- **文漫兼备，智能裁定**：一页一图的画册与漫画自动转入轻量图像引擎，直解图档，免去 WebView 渲染管线的冗长开销。

## 获取与安装

前往 [Releases](../../releases) 下载最新版 `app-release.apk`，可通过 `adb install` 命令行推送或设备自带的文件管理器直接安装。

- **系统要求**：Android 11（API 30）及以上。
- **实测机型**：墨案 Pantone 6（Android 14，6 英寸彩墨屏，1072 × 1448 分辨率）。
- **兼容说明**：理论上适用于绝大多数同系统版本的电子墨水屏设备。因各厂商品牌的屏幕驱动与刷新机制存在差异，若在其他机型上遇到布局或刷新异常，欢迎随时反馈。

## 使用指引

### 书库整理与陈列

1. **按目录归整书籍**：将 EPUB 书籍放入设备本地存储（例如 `/sdcard/Books/`）：
   - **单行本**：根目录下的独立 `.epub` 文件，在书架上平铺陈列；
   - **系列套书**：根目录下的子文件夹自动归纳为整套合集，右上角标注总册数（递归收录各级子目录中的所有 `.epub`）；
   - **专属封面**：文件夹内若有名为 `cover.jpg` 或 `cover.png` 的图像，优先作为整套封面；若无，则自动撷取卷首首册封面。
2. **初次载入**：启动应用后进入设置，点选「书库文件夹」授予目录读取权限，扫描完成即刻陈列书架（300 册藏书全量初扫约 9 秒，后续增量扫描仅需约 1 秒）。
3. **书架流转**：书架采用 4 × 3 经典网格整屏排布，依最近阅读时序流转。上下滑动或轻触页脚即可整屏翻阅；在首屏向下拉动，即可唤出搜索框与设置面板。

### 沉浸阅读交互

- **从容翻页**：
  - 屏幕左右两侧各 1/3 区域轻触均判定为「下一页」（左右手单手换持皆自然顺手）；
  - 屏幕向右滑动返回「上一页」；
  - 轻触屏幕中央区域呼出阅读工具条；
  - 完整适配设备实体翻页键与音量键。
- **三重排版引擎**（按书独立记忆，各取所长）：
  - **文字模式**：基于原生 `StaticLayout` 构建的极速自研排版引擎。剔除出版商繁琐样式干扰，专注于纯粹骨架与字体排版，响应迅捷，瞬翻即显；
  - **原版模式**：基于 Readium（WebView）渲染。原汁原味保真出版商的复杂版式，完美呈现竖排、古籍排版、内嵌定制字体与复杂图文混排；
  - **漫画模式**：底层直读解压图片，绕过排版管线，极速载入画幅。
- **版式与字体**：
  - 工具条归纳为「目录」、「字体」（字体 · 字号 · 粗细）与「版式」（行距 · 左右 · 上下）三组；字号、行距、边距及字重描边均配备离散级滑块，松手即定；
  - 支持外置字体扩充：在字体列表末项授权本地字体目录（默认定位 `/sdcard/Fonts`），即可选用私藏字体。
- **雅致页眉与页脚**：
  - 页面顶部淡印当前章节名称；
  - 页脚左侧静置系统当前时间，右侧展示全书页码（纯文本书采用动态渐进校准算法）。

## 技术实现

- **界面与交互**：Kotlin + Jetpack Compose。彻底剥离系统多余动画（Ripple / Crossfade / 转场），全量操作落实为单帧瞬绘。
- **数据持久化**：Room（书籍与套系数据）、DataStore Preferences（阅读配置与偏好）。
- **图像与封面**：Coil。针对墨水屏（Kaleido）色彩衰减特性进行专属伽马补偿与饱和度提亮，1:1 精准映射书架网格像素。
- **核心排版与解析**：
  - **EPUB 解码**：轻量级 ZIP 与 OPF 结构自研流式解析器，零冗余第三方黑盒依赖；
  - **原生排版引擎**：结合 Android 原生 `StaticLayout` 深度定制章节分页与断行调度；
  - **原版还原引擎**：接入 [Readium Kotlin Toolkit](https://github.com/readium/kotlin-toolkit) 3.3，兼顾复杂版面还原度。

关于设计原则与架构边界详见 [SPEC.md](SPEC.md)，工程决策与墨水屏优化细节详见 [CLAUDE.md](CLAUDE.md)。

## 源码构建

### 编译与安装

```sh
export JAVA_HOME=/opt/homebrew/opt/openjdk@17   # 推荐 JDK 17
./gradlew :app:assembleRelease
adb install -r app/build/outputs/apk/release/app-release.apk
```

- **SDK 配置**：确保 `local.properties` 中已正确指定 Android SDK 路径；
- **签名说明**：若项目根目录下存在 `keystore.properties`（包含 `storeFile`、`storePassword`、`keyAlias`、`keyPassword`），构建脚本将采用正式证书签名；缺失时则自动回退为 debug 签名（注：自定义构建版本与 Releases 官方预编译包签名不同，无法直接覆盖安装）。

### 测试与辅助脚本

- **JVM 单元测试**：`./gradlew :app:testDebugUnitTest`
- **合成测试书库**：`python3 tools/gen_test_library.py`

## 设计取舍与已知限制

为恪守「轻巧、纯粹、克制」的初衷，项目在现阶段明确了如下边界与取舍：

- **专注于 EPUB**：目前仅支持 EPUB 格式（含流式文本与图文漫画），暂不扩展 MOBI、AZW3、PDF 等异构格式。
- **原生排版特性**：原生文字模式基于系统原生文字排版接口，受 Android 平台能力限制（API 34 尚无完整两端微调机制），段落末尾可能会留存不足一字的微小参差；表格元素降级平铺为线性文字。
- **方向锁定**：阅读与交互全程锁止为竖屏，暂不支持横屏双页。
- **系统级墨水屏刷新**：不调用私有刷新接口或注入伪黑帧，屏幕残影清除与全刷机制完全托付给系统底层调度，保持纯粹，不增设繁杂的额外开关。
